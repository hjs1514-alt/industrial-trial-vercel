# 산업혁명 역사재판 — 배포 안내

중학교 2학년 역사 수업용 모의재판 웹앱입니다. 학생은 로그인 없이 링크만 열면 됩니다.

---

## 이 앱이 하는 일

산업혁명을 **피고인석에 세운 재판**입니다. 학생은 변호인석과 검사석 중 한 자리를 고르고,
실제 형사재판 순서를 그대로 따라갑니다.

> 개정 → 인정신문 → 자리 선택 → 모두진술 → 서증 제출(증 제1~3호증) → 증거 인부
> → 증인 선서 → 주신문 → 반대신문 → 재주신문 → 피고인 신문
> → 최종 진술 → 최후진술 → 결심 → 평결 → 선고

마지막에 판사가 "이 법정의 배심원은 방금까지 변론하신 그분 한 사람뿐"이라고 말합니다.
학생은 자기가 편들어 싸운 사건을 스스로 판단해야 합니다.

**AI가 맡는 역할은 셋뿐입니다.** 반대편 당사자, 증인, 피고인 산업혁명.
판사 대사는 전부 고정 대본이고 AI를 쓰지 않습니다. **판결은 AI가 내리지 않습니다.**

용어는 눌러서 뜻을 볼 수 있고, 판사가 매 단계마다 그 절차가 무엇인지 쉬운 말로 풀어 줍니다.

## 1단계 · GitHub에 올리기

압축을 풀고 그 폴더에서:

```bash
git init
git add .
git commit -m "산업혁명 역사재판"
git branch -M main
git remote add origin https://github.com/내계정/industrial-trial.git
git push -u origin main
```

`.gitignore`에 `.env`가 들어 있어서 **API 키는 올라가지 않습니다.**
`.env` 파일은 절대 커밋하지 마세요.

---

## 2단계 · Vercel에 배포하기

1. [vercel.com](https://vercel.com) → Add New → Project → 방금 올린 저장소 선택
2. Framework 는 Vite 로 자동 인식됩니다. 그대로 두세요.
3. **Environment Variables** 에 다음을 넣습니다.

| 이름 | 값 |
|---|---|
| `OPENAI_API_KEY` | OpenAI에서 발급받은 키 |
| `OPENAI_MODEL` | 쓸 모델 이름 |
| `TRIAL_PASSCODE` | 수업용 입장 암호 (비워도 됨) |

학생 기록은 브라우저 안(localStorage)에 저장되어 새로고침해도 이어서 할 수 있고,
재판이 끝나면 PDF 로 내려받습니다. 서버에 학생 정보를 남기지 않습니다.

`OPENAI_MODEL`은 [공식 모델 목록](https://platform.openai.com/docs/models)에서 현재 쓸 수 있는
이름을 확인해 넣으세요. **최상위 모델은 필요 없습니다.** 중간 등급이면 충분합니다.
모델을 바꿔도 코드는 고칠 필요가 없습니다. 값만 바꾸고 다시 배포하면 됩니다.

4. Deploy 를 누르면 주소가 나옵니다.

## 미성년자 대상 운영에서 챙길 것

이 앱은 조건이 유리한 편입니다. 주제가 산업혁명 하나로 고정돼 있고, 자유 채팅이 아니며,
로그인이 없어 학생 개인정보를 **아예 수집하지 않습니다.** 여기에 세 가지만 더하세요.

- **감독 하 사용** — 링크를 상시 공개하지 말고 수업 시간에만 여세요. 숙제로 내주는 것은 권하지 않습니다.
- **AI 사용 고지** — 입장 화면에 이미 넣어 두었습니다. "상대편과 증인, 피고인은 AI가 연기하며 실제 인물의 발언이 아닙니다."
- **신고 경로** — 이상한 답변이 나오면 학생이 선생님께 바로 알리도록 미리 안내하세요.

## 안전장치가 어떻게 걸려 있는지

- API 키는 `api/trial.js` 안에만 있습니다. 학생 브라우저로 내려가지 않습니다.
- **프롬프트도 서버에서 조립합니다.** 학생이 요청을 조작해 이 앱을 일반 챗봇으로 바꿔 쓸 수 없습니다.
- 역할은 7가지로 고정돼 있고, 목록에 없는 요청은 거부됩니다.
- 한 사람이 1분에 12번 넘게 부르면 잠시 막힙니다.
- 입력 길이에 상한이 걸려 있어 긴 글을 밀어 넣을 수 없습니다.

## 자주 손보게 되는 곳

| 바꾸고 싶은 것 | 파일 | 찾을 것 |
|---|---|---|
| 판사 대사 | `src/data.js` | `JUDGE` |
| 증인 목록·성격 | `src/data.js` + `api/_prompts.js` | `WITNESSES`, `WITNESS_PERSONA` |
| 인물이 서는 자리 | `src/Courtroom.jsx` | `MARK` |
| 용어 풀이 | `src/data.js` | `GLOSSARY` |
| 재판 시간 | `src/data.js` | `TOTAL_MIN` (분 단위 한 곳만 고치면 됩니다) |
| AI 반박 강도·길이 | `api/_prompts.js` | `DEPTH`, `buildPrompt` |
| 반대신문 횟수 | `src/App.jsx` | `runCross` 안의 `round <= 2` |

증인을 더 줄이거나 늘리고 싶다면 `src/data.js`의 `WITNESSES` 배열에서
항목을 지우거나 추가하면 됩니다. 대기석 배치와 인물 크기는 자동으로 맞춰집니다. 단, `api/_prompts.js` 의 `WITNESS_PERSONA` 도 함께 고쳐야 합니다.

## 다른 단원으로 바꾸기

재판 절차와 화면은 그대로 두고 내용만 갈아끼울 수 있습니다.
`api/_prompts.js`의 `HISTORY_BASE`(역사 지식), `WITNESS_PERSONA`(증인),
`src/data.js`의 `SEATS`(양쪽 입장)와 `JUDGE`(판사 대사)만 바꾸면
프랑스혁명이든 일제강점기든 같은 구조로 재판을 열 수 있습니다.

## 그림에 대해

`public/img/` 에 배경 1장과 인물 8장이 들어 있습니다. 모두 배경을 지운 투명 WebP 이고
전부 합쳐 660KB 남짓이라 학교 태블릿에서도 금방 뜹니다.

| 파일 | 쓰이는 곳 |
|---|---|
| `courtroom.webp` | 법정 배경 |
| `judge.webp` | 판사 |
| `lawyer-a.webp` | 학생이 선 자리 |
| `lawyer-b.webp` | 상대편 자리 |
| `child · woman · worker · owner · reformer` | 증인 다섯 |

### 인물이 서는 자리를 옮기려면

`src/Courtroom.jsx` 맨 위 `MARK` 의 숫자만 바꾸면 됩니다. 화면 크기 대비 비율이라
어떤 기기에서도 같은 자리에 섭니다.

- `cx` 가로 위치 (0이 왼쪽 끝, 1이 오른쪽 끝)
- `headY` 머리 꼭대기 높이
- `h` 키
- `clipY` **이 선 아래는 잘립니다.** 판사석·증인석·탁자 뒤에 선 것처럼 보이게 하는 값입니다.

### 피고인 「산업혁명」 그림

산업혁명은 사람이 아니라서 그림이 없습니다. 지금은 증기와 톱니로 된 형체를
코드로 그려 세워 두었습니다. 사람 모습의 그림을 쓰고 싶으시면 다른 인물들과
같은 화풍으로 한 장 만들어 `public/img/defendant.webp` 로 넣고,
`src/Courtroom.jsx` 의 `Defendant` 를 `<Actor img="defendant" ... />` 로 바꾸면 됩니다.

그림 생성에 쓸 만한 설명입니다.

> 19세기 영국 산업혁명을 사람으로 표현한 인물. 검댕 묻은 프록코트에 실크햇,
> 옷자락과 소매 끝이 증기와 연기로 흩어지고, 가슴께에 놋쇠 톱니바퀴가 박혀 있다.
> 표정은 담담하고 무겁다. 전신, 정면, 배경 없는 크림색 단색, 다른 인물들과 같은
> 채색 일러스트 화풍.
